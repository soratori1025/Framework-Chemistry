# Manuscript sources

LaTeX sources for

> *Evidence before prediction: a configuration-driven framework for testing how
> molecular descriptors shape property models*

prepared as a research article for the *Journal of Cheminformatics* (BMC),
together with its supplementary results (Additional file 1).

## Contents

| Path | Contents |
| :--- | :--- |
| `main.tex` | Main manuscript. BMC-style layout (A4, single column, Times, unnumbered headings, structured abstract, Vancouver references) built on the standard `article` class, so no journal class file is required. |
| `sections/` | Body of the manuscript: `background.tex`, `results.tex`, `discussion.tex`, `conclusions.tex`, `methods.tex`, `refs.tex`. |
| `figs/` | Figures 1--4 as vector PDF, generated by `../benchmarks/make_manuscript_figures.py`. |
| `supplementary/` | Additional file 1 (`additional_file_1.tex`) and its two figures. Plain `article` class; no journal class file is required. |

## Building

Any TeX Live 2023 or newer installation with `mathptmx`, `lmodern`, `booktabs`,
`caption`, `titlesec`, `listings`, `lineno` and `hyperref` is enough. From this
directory:

```bash
pdflatex main
pdflatex main
```

For Additional file 1:

```bash
cd supplementary
pdflatex additional_file_1
```

The main text is set at one-and-a-half spacing with line numbers, which is the
form the journal asks for during review. For a two-column-free, camera-ready
look, remove `\linenumbers` and `\onehalfspacing` from the preamble of
`main.tex`.

## Figures

All four main-text figures are produced from the archived result files, not
drawn by hand:

```bash
cd ../benchmarks
python make_manuscript_figures.py
```

| Figure | Source | File |
| :--- | :--- | :--- |
| Fig. 1 | fixed schematic of the five stages | `figs/fig1_pipeline.pdf` |
| Fig. 2 | descriptor effect, framework vs Chemprop (ten-split means) | `figs/fig3_descriptor_effect.pdf` |
| Fig. 3 | phenacetin worked example from `results/fig1_worked_example.json` | `figs/fig2_worked_example.pdf` |
| Fig. 4 | routing minus random control, per-split paired differences | `figs/fig4_routing.pdf` |

The files keep their generator names: `fig3_*` is Fig. 2 in the manuscript and
`fig2_*` is Fig. 3, because the floats are numbered in the order in which they
appear in the Results.

## Where the numbers come from

Every number in the manuscript and in Additional file 1 is derived from the
archived per-split results in [`../benchmarks/results/`](../benchmarks/results)
by the scripts described in [`../REPRODUCING.md`](../REPRODUCING.md):

* `benchmarks/paper_statistics.py` — paired comparisons, Nadeau--Bengio
  corrected intervals, Holm adjustment, minimum detectable differences.
* `benchmarks/generate_si_tables.py` — writes the Additional file 1 table bodies
  to `benchmarks/results/paper_tables/`.
* `benchmarks/report_manuscript_numbers.py` — prints every number quoted in the
  manuscript body and tables.
* `benchmarks/fig1_worked_example.py` — derives the phenacetin values used in
  Fig. 3 (ESOL, split 1) and in the Discussion.
* `benchmarks/make_manuscript_figures.py` — draws Figs. 1--4.

The study uses ten scaffold split manifests (`benchmarks/splits/`, seeds 1--10)
and five MoleculeNet endpoints (ESOL, FreeSolv, Lipophilicity, BBBP, BACE).
