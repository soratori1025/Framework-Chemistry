\section*{Abstract}

\noindent\textbf{Background.} When a chemist builds a machine-learning model for a molecular property, most of the attention goes to the learner: a graph neural network, a descriptor-based model, or a hybrid. In practice much of the outcome is decided earlier, by the quality of the data, by which of several hundred descriptors enter the model, and by the role those descriptors are given. These choices are usually buried in task-specific scripts, so a reader cannot tell which were tested, which were assumed, and which produced the reported score.

\noindent\textbf{Results.} We present \framework, an open-source workflow in which an experiment is declared in one validated configuration file and every run writes a record that can be replayed. We tested three hypotheses. \emph{H1, that training-partition evidence can guide descriptor choice}, is partly supported: subsets chosen from the scorecard beat random subsets of the same size at every budget tested, and significantly in 8 of 12 dataset--budget cells, but the rule ranked fourth of six selectors (mean rank 3.65). \emph{H2, that the effect of adding descriptors transfers between implementations}, holds on four of five endpoints: the framework and Chemprop v2.3.1 agreed in direction and approximate size ($+12.1\%$ versus $+19.7\%$ on FreeSolv; at most about $2\%$ elsewhere), while ESOL disagreed because one Chemprop run diverged and reached a test RMSE of $2.76$ on a single split, a failure that only the per-split record exposed. \emph{H3, that routes and predictive roles matter but are endpoint-specific}, holds: the full 210-descriptor hybrid led on ESOL and FreeSolv, the recommender route on Lipophilicity and graph-only on BACE, while on BBBP every route lay within $0.007$ AUROC. No compact route separated from its matched random control.

\noindent\textbf{Conclusions.} Evidence from the training partition is useful for narrowing choices, but it does not name a universal winner, and a mean that hides one divergent run is unfinished evidence. Declaring the audit, the descriptor evidence, the route and the role in one configuration makes these comparisons cheap to run and possible to audit. The framework does not prescribe a better predictor; it makes the alternatives testable on the user's own data.
